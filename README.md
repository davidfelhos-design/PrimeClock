# PrimeClock
Prime Clock is an experimental visual framework for exploring relationships between prime numbers, divisibility and periodic motion. Positive integers are generated by a reference hand, while prime numbers appear as rotating periodic hands on a common analog clock.

# PRIME CLOCK

## A Visual Framework for Exploring Prime Periodicity

**Version 1.0**
**First public release: September 8, 2026**
**Author: Dávid Felhős**

---

## Overview

Prime Clock is an experimental visual and structural framework for exploring relationships between prime numbers, divisibility and periodic motion.

The model represents the sequence of positive integers through the continuous rotation of a reference hand called **Hand 1**. Each complete revolution of Hand 1 represents the next positive integer.

Prime numbers are represented by additional rotating hands. Each prime hand moves according to its own period and returns to a common starting position at multiples of that prime.

The purpose of the Prime Clock is to provide a visual and intuitive perspective on periodic structures associated with prime numbers.

---

# How It Works

## 1. Hand 1 Generates the Positive Integers

Hand 1 is the reference hand of the system.

Every complete revolution represents the next positive integer:

```text
1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → ...
```

The number of completed revolutions therefore corresponds to the current positive integer.

---

## 2. Prime Hands

Each prime number is represented by a rotating hand.

For a prime number `p`, its hand rotates at:

```text
1/p
```

of the speed of Hand 1.

For example:

```text
Hand 2 → 1 revolution every 2 time units
Hand 3 → 1 revolution every 3 time units
Hand 5 → 1 revolution every 5 time units
Hand p → 1 revolution every p time units
```

---

## 3. The Common Starting Position

All hands share the same reference position at the top of the clock.

A prime hand representing the prime `p` returns to this position whenever the current integer is divisible by `p`.

Examples:

```text
6  → Hand 2 and Hand 3 are at the starting position

10 → Hand 2 and Hand 5 are at the starting position

15 → Hand 3 and Hand 5 are at the starting position
```

The position of a prime hand can therefore be described using modular arithmetic:

```text
position = n mod p
```

where:

* `n` is the current positive integer
* `p` is a prime number

---

## 4. How New Prime Hands Appear

When Hand 1 reaches the next positive integer, the model checks the previously established prime hands.

If the current integer is divisible by an earlier prime, at least one existing prime hand is at the common starting position.

If none of the existing prime hands returns to the starting position, the integer is prime.

The model then introduces a new prime hand.

Conceptually:

```text
Existing prime hand returns
to the starting position
            ↓
Integer is divisible by an earlier prime


No existing prime hand returns
to the starting position
            ↓
The integer is prime
            ↓
A new prime hand is introduced
```

# The Prime Clock Perspective

The Prime Clock separates two roles:

### Hand 1

Generates the sequence of positive integers through successive revolutions.

### Prime Hands

Represent recurring positions associated with divisibility by prime numbers.

In this representation:

```text
Hand 1 generates the sequence.

Prime hands represent periodic divisibility patterns within it.
```

The Prime Clock therefore provides a visual way to explore the following question:

> **Which positions in the sequence are already identified by the periodic returns of the existing prime hands, and when does the next previously unrepresented position correspond to a new prime?**

---

# Loading Any Position

The Prime Clock can be loaded directly at any positive integer.

The program reconstructs the state of the clock without animating all previous revolutions.

For every prime `p`, the position is calculated from:

```text
n mod p
```

This allows the periodic state of multiple prime hands to be examined simultaneously at different positions in the sequence.

# Relation to Earlier Periodic Approaches

The Prime Clock explores prime numbers through periodic motion and recurring patterns.

It therefore has a broad conceptual connection with other approaches that investigate prime-related periodic structures, including work associated with Michael T. M. Emmerich.

### Earlier periodic approaches

Investigate concepts such as:

* prime-related periodic structures
* modular states
* cycles
* recurring patterns

### The Prime Clock

Uses:

* one continuously moving reference hand
* successive revolutions to generate the positive integers
* rotating hands representing prime periods
* one common analog clock

The Prime Clock is presented as a visual framework for exploring these relationships.

# Scope of the Project

Prime Clock is an experimental visualization and structural framework.

The project uses established mathematical concepts including:

* prime numbers
* divisibility
* modular arithmetic
* periodicity

The Prime Clock does not claim to replace existing number theory or to provide a new proof concerning the distribution of prime numbers.

Its purpose is to document and explore this particular representation and the observations that may arise from it.

# Original Contribution

The Prime Clock project presents a particular visual representation in which:

1. A reference hand generates the sequence of positive integers.
2. Prime numbers are represented as independent periodic hands.
3. All prime periods are visualized on one common analog clock.
4. Divisibility is represented by the simultaneous return of prime hands to a common reference position.
5. The state of the system can be reconstructed directly at any positive integer.

The project documents this framework as **Prime Clock Version 1.0**.

# About the Project

Prime Clock was created by **Dávid Felhős**, an engineer with an interest in mathematics, visualization and computational exploration.

The project began with a simple question:
